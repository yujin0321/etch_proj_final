# ⚡ 반도체 식각 공정 지능형 관제 에이전트 시스템 (Smart Factory 프로젝트)

> **프로젝트 기간:** 2026.05.01 ~ 2026.05.24

---

## 1. 왜 이 프로젝트를 기획하게 되었을까?

반도체 수율의 핵심이라고 불리는 **식각(Etching) 공정**은 미세한 이상 징후나 센서의 변화(Drift)를 제때 잡아내지 못하면 순식간에 대량의 웨이퍼 불량(Scrap)으로 이어져 천문학적인 손실을 보게 됩니다. 

현장 실무자분들을 인터뷰하면서 두 가지 명확한 페인 포인트(Pain Point)를 발견하고 이를 해결하는 데 초점을 맞추었습니다.

1. **"90% 확률로 고장이니 장비를 멈추세요"라는 AI의 단순 경고는 믿을 수 없다.**
   - 수억 원을 호가하는 양산 설비를 세우려면 "왜 고장으로 판단했는지", "어떤 센서가 비정상인지"에 대한 정량적이고 확고한 근거가 필요합니다.
2. **SOP(표준작업절차) 매뉴얼이 엄격하지만, 주니어 엔지니어는 처음 겪는 이상 상황에 대처하기 어렵다.**
   - 단순 고장 진단을 넘어 과거 사례와 매뉴얼을 매핑해 주어, 경험이 부족한 엔지니어도 시니어급으로 빠르고 정확하게 초기 대응을 할 수 있도록 돕는 시스템을 만들고자 했습니다.

## 2. 대상 장비 및 분석 데이터셋

### ⚙️ 타깃 설비: LAM 9600 Metal Etcher
저희 팀은 실제 현장에서 널리 쓰이는 금속 식각 장비인 **LAM 9600** 모델을 타깃 장비로 설정하고, 공정 중 발생하는 물리·화학·전기 신호의 다중 센서 데이터를 통합하여 분석했습니다.

* **물리 제어 센서 (EV):** $BCl_3 / Cl_2$ 가스 유량, 챔버 압력, He 냉각 압력, Vat Valve 상태 등
* **화학 반응 모니터링 (OES):** 245~800 nm 발광 스펙트럼 데이터를 분석하여 $Al(395\,nm)$, $Ti(336\,nm)$, $Si(250\,nm)$ 등 식각 산출물 추적
* **전기 신호 센서 (RFM):** S1~S4 4개 채널의 전압, 전류, 위상(Phase) 분석을 통한 플라즈마 점화 및 RF 전력 전달 효율 측정

## 3. 시스템 아키텍처 및 핵심 파이프라인

데이터가 들어오는 순간부터 엔지니어에게 알림이 가기까지의 전 과정(End-to-End)을 실시간 자동화 에이전트 시스템으로 구축했습니다.

```text
[Apache Kafka] 실시간 데이터 스트리밍 플랫폼에서 이벤트를 push/pull 처리
       ↓
[1단계: Autoencoder] 비지도 학습 기반으로 센서 데이터 재구성 오차(MSE) 계산 후 이상 탐지
       ↓ (정상 임계치를 초과하는 순간 정밀 진단 레이어로 전송)
[2단계: LightGBM] 지도 학습 기반으로 다중 결함 분류 수행 및 상위 3개 결함 후보군 추출
       ↓
[3단계: SHAP Agent] 분류 판단에 가장 큰 영향을 준 상위 기여 센서 및 이탈 방향 추적
       ↓
[4단계: GraphRAG Agent] Neo4j 지식 그래프를 탐색하여 이상 센서에 맞는 원인-위험-SOP 매핑
       ↓
[5단계: UI / Slack] React 대시보드 화면에 실시간 차트 렌더링 및 Slack 채널 알림 발송

## 4. 우리 프로젝트만의 차별화된 핵심 기술 (Core Tech)

### ① 데이터 부족 문제를 해결한 '5가지 시계열 증강 전략'
정상 데이터(83.9%)에 비해 고장 데이터(16.1%)가 터무니없이 부족한 극심한 클래스 불균형 문제를 겪었습니다. 이를 해결하기 위해 단순 복제가 아닌 **물리적 의미와 주기성을 보존하는 5가지 복합 증강 기법**을 적용하여, 데이터를 기존 대비 **173% 확장(3,950행 → 10,790행)**했습니다.

* **Jitter:** 원본 시계열에 가우시안 미세 노이즈를 더해 실제 센서의 측정 환경을 모사했습니다.
* **Time Warp:** 시간축을 비균일하게 늘리거나 압축하여 플라즈마 안정화 속도나 식각 속도의 변동성을 시뮬레이션했습니다.
* **Magnitude Warp:** 시간축을 따라 서서히 변하는 배율 커브를 적용해 공정 중 전력 레벨이나 가스 농도의 자연스러운 변동을 반영했습니다.
* **Scaling + Jitter:** 신호 레벨 스케일을 조정한 후 노이즈를 결합하여 장비 노후화에 따른 다양성을 확보했습니다.
* **PGHA (Pattern-Guided Harmonic Augmentation):** RF 전력이나 OES 스펙트럼처럼 주기성을 띠는 신호의 조화파 성분을 모델이 학습하여 물리적 특성을 깨뜨리지 않고 정밀하게 샘플을 생성했습니다.
* *(검증 결과, 원본 데이터와 상관구조 보존도 99.7%, 통계적 유사도 97.4%라는 높은 점수를 기록했습니다.)*

### ② 현장 적응력을 높인 '모델 고도화 및 5단계 판별 로직'
* **인프라 레이어 가속:** 초당 수십 건씩 밀려드는 데이터 지연을 막기 위해 Pandas를 거치지 않고 Numpy 배열과 GPU 메모리 자동 할당(PyTorch Tensor)을 연동했습니다. 예기치 못한 데이터 누락 시에도 서버가 멈추지 않도록 방지책을 설계했습니다.
* **Sliding Window 동적 임계치:** 장비가 노후화되거나 챔버 환경이 미세하게 변하면 정상 수치도 자연스럽게 변합니다(Drift 현상). 이를 고장으로 잘못 판단(과탐지)하지 않도록, `deque`를 활용해 최근 정상 데이터의 흐름에 맞춰 임계치를 스스로 업데이트하는 동적 알고리즘을 구현했습니다.
* **5단계 판별 로직 및 Top-3 추출:** Autoencoder의 비지도 학습 능력과 LightGBM의 지도 학습 능력을 유기적으로 결합했습니다. 오차 수치에 따라 Anomaly/Suspect/Normal 구간을 나누고 확신도 기준을 다르게 적용했으며, 정상 확률을 배제한 채 가장 가능성 높은 3가지 결함 후보군을 재정규화해 보여줌으로써 실질적인 진단 재현율을 크게 끌어올렸습니다.

### ③ SHAP 분석과 Neo4j 지식 그래프를 융합한 'GraphRAG 진단'
* **SHAP Agent:** AI가 판단한 고장 근거를 엔지니어가 납득할 수 있도록, 상위 기여 센서들의 현재 수치, 평균값, 정상 범위를 분석해 High/Low 이탈 방향을 정량적으로 뽑아냅니다.
* **Neo4j 기반 지식 그래프:** 장비, 센서, 고장 메커니즘, SOP 매뉴얼의 유기적인 관계망을 116개 노드와 208개 관계 타입으로 촘촘하게 구축했습니다.
* **LLM Report 코멘트:** GPT-4o(Temperature=0)와 LangChain을 활용해 딱딱한 데이터 덤프를 "반도체 공정 시니어 엔지니어"의 시선으로 번역하여, 구체적으로 어떤 의심 부품(예: Throttle Valve, Vacuum Pump 등)을 점검해야 하는지 실무 중심의 한국어 진단 보고서를 자동 생성합니다.

### ④ 장시간 관제를 고려한 UI/UX 및 실시간 알림
* **React + FastAPI WebSocket:** 데이터 스트리밍의 지연을 최소화하기 위해 웹소켓 파이프라인을 구축하고 Plotly를 활용해 실시간 차트를 매끄럽게 렌더링했습니다.
* **Premium Dark Mode & 다이내믹 알림:** 장시간 모니터링하는 현장 엔지니어의 피로도를 낮추기 위해 딥 다크 모드 톤으로 디자인했으며, 이상 징후가 감지되는 순간 대시보드가 Green에서 Red 테마로 즉각 전환됩니다. 동시에 지정된 Slack 채널(`#fab-alerts`)로 실시간 경고 메시지가 자동 전송됩니다.
